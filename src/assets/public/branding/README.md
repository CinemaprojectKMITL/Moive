# CEDT — Widescreen Cut

An original cinema identity built from custom vector letterforms.

## Three directions considered
- A — Widescreen Cut: broad geometric lettering, shaped terminals and a fine screen-edge curve. Bold, modern and premium.
- B — Premiere Serif: tailored serif lettering and generous spacing, inspired by premiere invitations and cinema title cards.
- C — Projection Line: geometric lettering with an aligned slit suggesting projected light.

Direction A was selected for its readable silhouette, compact header proportions and distinctive C that also works as a monogram.

## Meaning
The open C suggests the boundary of a cinema screen. Its gold terminal marks the transition from the dark auditorium into the picture. The broad lettering conveys the widescreen format; the shallow gold arc beneath the full wordmark echoes a cinema screen edge. Red supplies the entertainment energy, with gold confined to a restrained accent.

SVG backgrounds are transparent. All lettering is outlined geometry, with no font dependency, external resource, embedded raster image, script, filter or gradient. The responsive version removes the fine screen arc. The icon uses the exact C from the wordmark. SVGs include accessible titles and descriptions.

## Colors
Cinema red: #ED263B. Champagne gold: #C8A66A. Recommended screen background: #0B0B0E.

## Web use
Copy this branding directory to public/branding/ in the existing project.

```html
<img src="/branding/cedt-logo-responsive.svg" alt="CEDT Cinema" width="156" height="41">
<link rel="icon" type="image/svg+xml" href="/branding/cedt-logo-icon.svg">
```

Use the SVG assets for display and JPGs for review only. Preserve the aspect ratio and intrinsic padding; leave at least one letter-stem width of additional clear space around the mark. The full and responsive versions share the same letter geometry. Inline SVG users should make the title/description IDs unique if placing multiple copies in one document. The small-size recommendations are visual guidelines, not hardcoded breakpoints.

No reference image was accessible in this turn. The supplied written brief and specified palette informed the design.
